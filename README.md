 # Global Superstore Sales Analysis | Power BI

## Project Overview
An interactive Power BI dashboard built to analyze Global Superstore sales, profit, customer behavior, product performance, and regional trends.

## Key Features
- Sales and profit KPIs
- Yearly, monthly, and quarterly sales trends
- Country and regional performance analysis
- Product and category analysis
- Customer and order analysis
- Return analysis and interactive report filters
